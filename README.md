# Finran (Finroles)

An elite, high-fidelity editorial recruitment platform designed for luxury finance, private capital firms, and executive search.

## Design Architecture
- **Editorial Typography System**: Implements high-precision structural grid layouts, dramatic font scaling, and controlled rhythm.
- **Asymmetrical Target Profiles Bento Grid**: Differentiates candidates using varied card visual weight, custom transaction flowcharts, and live audit ledgers.
- **Vetting-as-a-Service Timeline**: Combines dense technical panels and spacious, minimalist editorial screens.
- **Layered 3D Stacking**: Showcases vetting protocol layers using physical offsets, drop shadows, and subtle reflections.
- **Featured Opportunities Board**: Features a dominant, dark-theme mandate alongside clean, supporting role registries.
